Production essentials
  • Set a strong SECRET_KEY and ADMIN_PASSWORD; the app refuses to start in production without them.
  • Use PostgreSQL, not SQLite, for production concurrency and backups.
  • Terminate TLS at the reverse proxy and keep secure cookies enabled behind HTTPS.
  • Run flask db upgrade before starting each new release.

Maintenance

Release checklist

  1. Back up the PostgreSQL database.
  2. Deploy code and install requirements.
  3. Run migrations and verify activation.
  4. Restart Gunicorn and check this page.
  5. Confirm admin login, student login and plan generation.
